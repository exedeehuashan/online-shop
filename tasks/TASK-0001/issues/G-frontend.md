# Build React order workflows

使用 React、TypeScript、TanStack Router 和 TanStack Query 实现订单流程。

## Acceptance criteria

- 提供创建、列表、详情、确认和取消页面。
- 覆盖 loading、empty、validation、conflict 和 retry 状态。
- 组件测试遵循 TDD，并具备可访问性基线。
- API client 集中维护或由 OpenAPI 生成。
- 测试 fixture 以组合方式构建。

## Dependency

Blocked by versioned REST API.
